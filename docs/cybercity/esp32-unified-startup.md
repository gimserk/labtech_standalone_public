# Cyber City ESP32 unified startup — prototype

This milestone connects the existing Cyber City component chain without
changing Django models, endpoints, building settings or GPIO mappings.

## Prerequisites
- City Control VM running the MQTT broker, accessible to the ESP32.
- Existing CyberCity broker address/port and building MQTT base topic set.
- ESP32 registered by Wi-Fi MAC under the building in LabTech.
- Provisioning key generated by `issue_cybercity_esp32_key <MAC>`.
- MicroPython board with `urequests` and `umqtt.simple` installed.
- Device-side `bootstrap_config.py` and `mqtt_secrets.py` set outside Git.
- Trustworthy HTTPS certificate verification. IMPORTANT: many MicroPython
  `urequests` builds do **not** validate certificates. The provided example
  is NOT secure against an untrusted network unless its TLS implementation
  has been verified; do not use it in production or across untrusted Wi-Fi.
- Broker should use per-device ACLs and authenticated, certificate-validated
  MQTT over TLS before untrusted clients are onboarded. The included
  `mqtt_controller.py` currently uses plaintext MQTT and is lab-only.

## Prototype test flow

1. Copy `bootstrap_config.example.py` to `bootstrap_config.py`, set
   the HTTPS LabTech URL, Wi-Fi info, and generated device key.
2. Copy `mqtt_secrets.example.py` to `mqtt_secrets.py` and set
   broker credentials approved for the test broker.
3. Upload `mqtt_controller.py`, `device_startup.py`, and the two
   configuration modules.
4. Run `import device_startup; device_startup.run()` in the REPL.
5. Verify it displays the assigned city, building and pin count.
6. Use existing Cyber City attack monitor controls to publish a command,
   and confirm the GPIO and retained `/status` update for the assigned pin.

This is **not** yet an auto-start-on-boot or auto-OTA deployment. Firmware
downloads remain staged separately and are never executed by this flow.
The device will stop on a connectivity failure; reconnect, last will,
watchdog, and fail-safe outputs will be developed and tested separately.
