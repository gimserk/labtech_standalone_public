# LabTech Standalone

LabTech is a standalone Django application. See the [Ubuntu native installation guide](docs/installation.md) for initial installation, [noninteractive in-place updates](docs/installation.md#noninteractive-production-upgrades-no-installer-questions), diagnostics, and backups. Ordinary upgrades use `sudo /opt/labtech/deploy/update.sh`, not `install.sh`.

For PBQ chapter assessments, see [PBQ activities](docs/operations/pbq-activities.md), including private artifact storage and backup requirements.

For theme authoring and browser checks, see [Light, dark, and high-contrast appearance](docs/operations/appearance.md).

For lab cloning options, see [Linked and full lab clones](docs/operations/lab-cloning.md).
