How configuration and OTA updates work

The updated Basic ESP32 controller checks LabTech for pin layout, WS2811 strip, and MQTT configuration changes about every 30 seconds while running. No hardware reset or manual restart is needed after you save. Applying a new layout briefly reconnects MQTT and resets managed outputs to OFF; resend commands to restore active states. Older controllers still require a manual restart or firmware update. Publishing firmware sets an OTA target, not a confirmed installation.

Pins

With updated Basic ESP32 firmware, pin changes are picked up automatically within about 30 seconds through the authenticated configuration API; changed settings reinitialize managed GPIO outputs in their safe OFF state. The bundled controller supports LED, duty-cycle, and WS2811 addressable RGB strips. When you select WS2811, set the addressable LED count and a safe brightness (default 64/255). Modes: OFF, NORMAL, WARNING, ERROR, INFO, MAINTENANCE, BUSY, RECOVERY, WHITE. I2C screen/LED modes require compatible custom firmware. For WS2811 use a safe data GPIO, shared ground, a level shifter as required, and an external power supply sized for the strip. Avoid GPIO2/3 on typical ESP32 DevKits.
