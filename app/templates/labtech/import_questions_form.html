CSV Formatting Instructions

Please ensure your CSV file has the following header row exactly as written:

question_text,question_type,points,choice1,choice2,choice3,choice4,choice5,choice6,correct_choice
  • question_type: Must be one of `MCQ`, `TF`, or `SA`.
  • MCQ: Fill in `choice` columns and set `correct_choice` to the number of the correct column (e.g., 1, 2, 3).
  • TF: Set `correct_choice` to `TRUE` or `FALSE`.
  • SA: Fill in `choice` columns with all acceptable correct answers.
